# Natural Disaster Prediction Using Machine Learning

## Project Overview

This project is a Machine Learning based Natural Disaster Prediction System developed using Python in Google Colab.  
The system analyzes disaster-related data and predicts the type of disaster using Machine Learning algorithms.

The project uses a real-world dataset containing natural disaster records from 2000 to 2025.

---

# Objectives

- To understand the Data Science workflow
- To preprocess and clean real-world datasets
- To train a Machine Learning model
- To predict disaster types based on geographical and disaster-related features
- To evaluate model accuracy
